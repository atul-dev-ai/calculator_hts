# 🧮 Premium Glassmorphism Calculator

A stunning, responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.  
This project has been revamped with a modern **Glassmorphism UI** and includes advanced arithmetic operations with an interactive, user-friendly interface.

---

## ✨ Features

- 🎨 **Premium Glassmorphism Design:** Beautiful dark gradient background with frosted glass effects.
- 📋 **Copy to Clipboard:** One-click copy functionality for your results.
- ➕ **Basic Arithmetic:** Addition, Subtraction, Multiplication, Division, and Percentage.
- 🧮 **Advanced Math:** Square Root (√) and Factorial (!).
- 🧹 **Clear & Delete:** Clear All (AC) and Delete (DEL) functionalities.
- 🔄 **Real-time Display Updates:** Smoothly handles user input with error handling (e.g., dividing by zero).
- 📱 **Fully Responsive:** Clean layout that looks great on any screen.

---

## 🛠️ Tech Stack

- **HTML** – Semantic Structure  
- **CSS** – Glassmorphism, CSS Grid, Flexbox, & Animations  
- **JavaScript** – Core Logic, Math operations, Clipboard API
